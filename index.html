How the cipher works

Each cell is one bit. A generation is C[i] = F(B)[i] ⊕ A[i], where A and B are two consecutive states. Because the rule reads only B, it inverts exactly: P[i] = F(A)[i] ⊕ B[i].

The pair travels as (A,B) → (B, F(B)⊕A) going forward and (A,B) → (F(A)⊕B, A) going back. Starting from (IV, plaintext) and running G steps gives (xᴳ⁻¹, xᴳ) — both halves must be transmitted, which is why the ciphertext is twice the grid size.

F mixes the Moore-neighbourhood sum with key-derived nonlinear AND terms, plus a position-dependent salt so that uniform regions can't survive.
